Hardware UI Workflow & Modal Shift Map

“If I want to do X, what do I press?”
White Label: Primary Action Blue Label: Hold Shift + Control Encoders: Turn • Click • Hold+Turn • Hold 1s Menu Jump: Hold Sound Edit + Section Btn
1. Modulation Matrix (7×13) Top-Left
  • • Browse Grid: Turn Matrix (L→R). Shift+Turn = Up/Down in column.
  • • Set Amount: Click Matrix (Amount LED lit) → Turn → Click to exit.
  • • Fast Edit / Clear: Hold+Turn Matrix = instant offset. Hold 1s = reset to 0.
  • • Assign Custom (9 slots): Shift+Assign 1/2/3 selects Page 1–3. Hold Assign 1/2/3 + Turn any Knob (or turn Matrix to modulate a Mod Routing's Amount, or turn Preset for non-knob targets).
2. Digital Oscillators (1 & 2) Orange Knobs
  • • Select / Peek: Tap Select (Osc 1/2). Long-press Select = peek values on OLED without moving knobs!
  • • Tune: Turn = Semitones (±48) • Click = Fine cents • Shift+Turn = Octaves.
  • • Pick Sample / Wavetable (Osc 1): Shift+Turn Type (or Sound Edit + Select).
  • • Mix vs. Filter Mode: Shift+Volume balances Osc 1/2. When Osc 2 = Filter/Destroy, LED turns Pale Blue (Vol 1 = Drive into Osc 2; Vol 2 = Dry/Wet).
3. Filter, CycEnv & Voicing Center-Right
  • • Analog VCF: Type = LPF / BPF / HPF. Env/Velo (0 @ center) sets Env depth; Shift+Turn sets Velocity → VCF Env.
  • • Key Track Filter: Matrix Keyboard → Cutoff = 50 (tracks 1:1 across keys).
  • • Cycling Env: Mode = Env (ADSD), Run (Mono free loop), Loop (Poly retrig loop). Shift+Rise/Fall = Curve shape (Exp ↔ Linear ↔ Log).
  • • Voicing Mode: Mono • Poly (6v) • Para (12v, disables Osc 2) • Uni (up to 6 stacked).
4. Digital FX (1–3) & Tempo Far-Right
  • • FX Select LEDs: Bright = Editing • Dim = Active (On) • Unlit = Bypassed (Off).
  • • Toggle & Subtype: Click Type/Sub = On/Off • Shift+Turn Type/Sub = Subtype preset.
  • • Insert vs. Send (Delay/Reverb): Hold Sound Edit + FX Select (Amount = Send Level).
  • • Tempo Encoder: Turn = BPM • Click = Time Div (Hold+Turn locks Straight/Dotted/Triplet) • Shift+Turn = Swing (50–75%) • Shift+Click = Metronome On/Off!
Modal A: Presets & Favorites Blue / Red Pads
  • • Save / Rename: Tap Save → Tap Save again (quick overwrite), OR click Preset to step: Slot # → Type → Name (Turn=Char, Shift+Turn=A/a/0, Click=Next, Hold+Turn=Cursor).
  • • Enter Favorites (Shift+Panel): Step pads 1–16 (×4 pages = 64 slots) light Blue (saved) or Red (active).
  • • Load / Store / Erase Fav: Tap Blue pad = Load • Hold Save + Pad = Store • Hold Seq(Erase) + Pad = Clear • Tap Sound Edit = Exit.
Modal B: Arp, Seq & 4 Mod Lanes White / Red / Blue
  • • Arp → Seq Transfer: While playing Arp, long-press Record to copy Arp notes into the Sequencer!
  • • Step vs. Real-Time Rec: Press Rec while Stopped = Step Rec (Shift+Rec toggles Blue Overdub vs Red Replace). Press Rec while Playing = Live Rec.
  • • Quick Step Edit: Hold Step Pad → Turn Preset to pick note (Long-click = delete), Strip 1 = Length, Strip 2 = Velocity.
  • • 4 Mod Lanes: Tap Mods → Rec + move knob, OR hold Step + turn knob.
Modal C: LFO Shaper Wave Edit Purple / Red Strips
  • • Enter (Shift + LFO Select): Step pads blink Purple, Touch Strips turn Red, Page pads set Slope (/ \ ^ -).
  • • Edit Step vs. Segment: Hold step (or long-hold until flashing White for hands-free Step Edit; required for multi-step Segments!). Strip 1 = Amplitude, Strip 2 = Curve, Pads 16–64 = Slope.
  • • Save Shaper: Hold Save + LFO Select → pick User Slot 1–8 (or save Preset for 2 per-preset slots). Tip: Set Touch Sens = Medium!
Modal D: Touch Strip Modes Wht / Blu / Org / Red
  • • Vibrato LFO (Shift + Bend/Wheel): Top Wheel LED turns Blue. Hold Bend/Wheel pad: Strip 1 = Rate, Strip 2 = Depth (stays running across strip modes!).
  • • Macro Assign (Shift + Macros): Strips pulse White. Tap Strip 1 (M1) or Strip 2 (M2) → move up to 4 knobs/Matrix points. Long-click Preset = clear slot.
  • • Gate / Spice & Dice: Strip 1 = Gate %, Strip 2 = Spice amount. Shift + Gate/Spice = roll Dice (new non-destructive random seed).

Sound Edit Menus (Saved Per-Preset) White LED
0. Preset Volume (Top item)
Offsets current preset level (-12 dB to +6 dB) to match other patches.
1. Osc (Manual calls this “Pitch” in ch. 5/9/12!) SE + Osc Select
  • • Wavetable / Sample Select: Browse Osc 1 tables/samples.
  • • Osc1 / Osc2 Mod Quant: Quantize pitch mod to scales (Chromatic, Oct, 5th, Maj/Min, Pentatonic, Phrygian).
  • • Glide Mode: Time (constant time), Rate (constant speed/semitone), or Sync — each with optional Legato.
  • • Vibrato Depth & Vib Rate: Config for the 3rd Vibrato LFO.
2. FX SE + FX Select
• Delay Routing & Reverb Routing: Insert (serial chain) vs. Send (parallel split; Amount knob becomes Send Level).
3. Envelope (VCA ADSR) SE + Env Mode
  • • Velo > VCA / VCF / Env / Time: Independent velocity sensitivity for Volume, Cutoff, Matrix Env depth, and Decay/Release extension.
  • • Retrig Mode: Env Reset (restarts from 0) vs. Env Continue (picks up from current level; huge in Mono/Para/Uni!).
  • • Attack / Decay / Release Curves: Default vs. Quick / Percussive.
4. Voice (Manual ch. 12.3 mislabels “Keyboard”) SE + Env Mode
  • • Legato Mono: Whether Mono/Uni-Mono retriggers on legato notes.
  • • Unison Spread / Count (2–6) / Mode (Mono, Poly, Para).
  • • Poly Allocation: Cycle (round-robin), Reassign (same note reuses same voice), Reset (always starts Voice 1).
  • • Poly Steal Mode: Oldest, Lowest Velo, None (never steals lowest note!).
  • • Osc Free Run: Free-running oscillator phase vs. key-reset.
5. Cycling Env & 6. LFO & 7. Keyboard & 8. Seq & 9. Scale
  • • Cycling Env: Retrig Src (Poly/Mono/Legato/LFO1-2), Stage Order (RHF hold high vs RFH/HRF hold at 0), Tempo Sync.
  • • LFO: LFO 1/2 Retrig, Sync Filter (Straight/Triplet/Dotted), Shaper Rate (Per Step vs. All Steps = 16× faster).
  • • Keyboard: Matrix Src VeloAT (Velo / AT / Both), Kbd Src (Linear / S-Curve / Random / Voices), Bend Range (1–12 st).
  • • Seq: Smooth Mod 1–4 (on/off), -1 / +1 Semitone saved transpose.
Utility Menu (Global) Shift + Sound Edit
1. Preset Operations
• Preset Copy / Paste (Osc 1/2, FX 1/2/3, Seq+Mods, LFO Curve, Swap FX) • Preset Erase (Init, Reload, Matrix, Seq, Mods, Macro 1/2) • Panel Mode (Favorite Panel vs. Knob Panel).
2. Controls (Feel & Response)
• Knob Catch: Jump (instant), Hook (wait till pass), Scale (smooth catch-up).
• Velocity / AT Curve: Linear, Log (light), Expo (heavy).
• AT Start / End Sens: Low, Mid, High pressure.
• Touch Button Sens: Low, Medium (best for Shaper!), High.
• Sustain Polarity: Normally Open / Closed.
3. Audio & Calibration
• Audio In Mode: Line vs. Microphone (Dynamic mics; no phantom power).
• Audio In Gain: -9 dB to +24 dB.
• Master Tune (±50c) • Stereo to Mono.
• Calib Cutoff & Calib Analog (1–2 min self-tune).
4. Sync & 5. MIDI
• Metronome (On/Off, Level, 1-Bar Rec Count-In).
• Clock Source (Auto/Int/USB/MIDI/Clock In), PPQ, Global Tempo.
• MIDI Local Control (On/Off) + MIDI Seq/Synth routing (4 modes: Normal, Controller+Module split, DAW transpose, etc.), Knob Send CC, Program Change.
6. Global Scale • 7. Misc • 8. Your Name
• Global Scale/Root • LED Intensity • Your Name (tags your patches & adds your name to Filter list!).
