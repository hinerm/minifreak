Hardware UI Workflow & Modal Shift Map

Component boarders match cards
1. Mod Matrix & Left Controls Cyan Outline
  • Matrix (7×13): Turn Matrix = L→R | Shift+Turn = Up/Down | Click (Amt LED) = edit | Hold+Turn = quick offset | Hold 1s = clear (0)
  • Assign 1–3 (9 slots): Shift+Assign 1–3 = Page 1–3 | Hold Assign + Turn Knob (Matrix = mod depth | Preset = VCA/Uni/LFO AM)
  • Hold/Tie: Toggles key/Arp sustain (or holds Seq transpose) | In Seq Step Rec: tap = Rest, hold keys + tap = Tie
  • Chord/Scales: Tap = toggle Chord | Shift+Chord = Scale Config
  • Glide: Portamento time (SE+Osc = Time/Rate/Sync/Legato)
2. Digital Oscillators (1 & 2) Orange Outline
  • Select & Params: Tap Select = Osc 1/2 | Orange Wave | Timbre | Shape knobs map to 3 model-specific OLED icons
  • Tune/Oct Encoder: Turn = Semitones (±48) | Click (Fine LED) = Cents | Shift+Turn = Octaves
  • Wavetable & Sample (Osc 1): Shift+Turn Type (or SE + Osc Select) browses tables/samples (shared by 7 Granular types)
  • Osc 2 Filter / Destroy: Select LED 2 turns Pale Blue (Osc 1 Vol = Input Drive | Osc 2 Vol = Dry/Wet)
3. Filter, CycEnv & Voicing Teal Outline
  • Analog VCF (12 dB): Type = LPF | BPF | HPF | Env/Velo (0 @ center) = Env depth | Shift+Turn = Velo → VCF Env (Kbd→Cut=50 tracks 1:1)
  • Cycling Env: Mode = Env (ADSD) | Run (Mono free loop) | Loop (Poly retrig loop) | Shift+Rise/Fall = Curve (Exp | Lin | Log)
  • Envelope & Voicing: ADSR = VCA amp | Mode = Mono | Poly (6v) | Para (12v, Osc 2 off) | Uni (2–6v) | SE+Mode = Env & Voice menus
4. Digital FX (1–3) & Tempo Indigo Outline
  • FX Select LEDs: Bright = Editing | Dim = Active (On) | Unlit = Bypassed (Off)
  • Type/Sub Encoder: Click = FX On/Off | Shift+Turn = Subtype preset (Master = main & headphone output)
  • Insert vs. Send: SE + FX Select sets Delay / Reverb to Insert (serial) or Send (parallel; Amount = Send Level)
  • Tempo/Swing Encoder: Turn = BPM (30–240) | Click+Turn = Time Div (Hold+Turn locks family) | Shift+Turn = Swing
Modal A: Vibrato, Macros & Spice/Dice Amber Outline
  • Vibrato (Shift+Bend/Wheel): Toggles 3rd triangle LFO (top Wheel LED = Blue; stays active across strip modes; SE+Osc also edits)
  • Macro Assign (Shift+Macros): Strips pulse White → tap Strip 1 (M1) or 2 (M2) → turn up to 4 knobs (Matrix/Preset = custom; Long-click = clear)
  • Gate, Spice & Dice: Gate = step length | Spice morphs Vel/Oct/Gate/Step/Env non-destructively | Shift+Gate/Spice = roll Dice
  • Keyboard Menu Jump: Hold Sound Edit + tap Touch Strip opens Bend Range | Matrix Src VeloAT | Kbd Src
Modal B: Arp, Seq & Mod Recording Green Outline
  • Arp → Seq Transfer: While playing Arp, long-press Record to copy active Arp notes into the Sequencer
  • Step vs. Live Rec: Rec Stopped = Step Rec (up to 6 notes/step) | Rec Playing = Live Rec | Shift+Rec = Blue Overdub vs Red Replace
  • Step Note Select: In Step Rec or while holding a Step pad, turn Preset = pick chord note | Long-click Preset = delete note/step
  • 4 Mod Lanes (Mods): Tap Mods → Rec + turn knob/strip, OR hold Step + turn knob | Turn Preset = lane 1–4 (Long-click = clear)
Modal C: LFO 1–2 & Shaper Waves Purple Outline
  • LFO 1 & 2: Tap Select = 1/2 (LEDs: Yellow + | Red -) | Click Rate = Sync | Shift+Rate = Retrig (Free, Poly, Mono, Legato, One…)
  • Load Shaper Wave: Turn Wave to Shaper, then Shift+Turn Wave previews Preset + 16 Factory + 8 User waves (release Shift to load)
  • Save Shaper Wave: Presets auto-save 1 Shaper/LFO | In Shaper Edit, Hold Save + LFO Select → Preset stores User Wave 1–8
Modal D: Presets, Save & Menus Red Outline
  • Browse & Init: Turn Preset → Click = load | Shift+Turn = Category Filter | Hold 2s = Init Preset
  • Save & Rename: Tap Save 2× (overwrite) | Click Preset = Slot # → Type → Name (Turn=Char | Shift=A/a/0 | Click=Next | Hold+Turn=Pos)
  • Menus & Panel: Sound Edit (White) = Preset Menu (SE+Btn jumps; tap cancels) | Shift+SE (Blue) = Global Utility (Shift+Save = Favs/Panel)

Sound Edit Menus (Saved Per-Preset) White LED
0. Preset Volume (Top item)
Offsets current preset level (-12 dB to +6 dB) to match other patches.
1. Osc (Manual calls this “Pitch” in ch. 5/9/12!) SE + Osc Select
  • Wavetable / Sample Select: Browse Osc 1 tables/samples.
  • Osc1 / Osc2 Mod Quant: Quantize pitch mod to scales (Chromatic, Oct, 5th, Maj/Min, Pentatonic, Phrygian).
  • Glide Mode: Time, Rate (speed/semitone), or Sync (each w/ optional Legato).
  • Vibrato Depth & Vib Rate: Config for the 3rd Vibrato LFO.
2. FX SE + FX Select
Delay Routing & Reverb Routing: Insert (serial chain) vs. Send (parallel split; Amount = Send Level).
3. Envelope (VCA ADSR) SE + Env Mode
  • Velo > VCA / VCF / Env / Time: Velocity depth for Vol, Cutoff, Matrix Env & Dec/Rel.
  • Retrig Mode: Env Reset (from 0) vs. Env Continue (from current level; huge in Mono/Para/Uni!).
  • Attack / Decay / Release Curves: Default vs. Quick / Percussive.
4. Voice (Manual ch. 12.3 mislabels “Keyboard”) SE + Env Mode
  • Legato Mono: Retrigger on legato notes | Osc Free Run: Free phase vs. key-reset.
  • Unison Spread / Count (2–6) / Mode (Mono, Poly, Para).
  • Poly Allocation: Cycle (round-robin), Reassign (reuses voice), Reset (Voice 1).
  • Poly Steal Mode: Oldest, Lowest Velo, None (never steals lowest note!).
5. Cycling Envelope SE + CycEnv Mode
Retrig Src: Poly, Mono, Legato, LFO 1/2 | Stage Order: RHF (hold high) vs. RFH/HRF (hold 0) | Tempo Sync.
6. LFO SE + LFO Select
LFO 1/2 Retrig | Sync Filter: Straight / Triplet / Dotted | Shaper Rate: Per Step vs. All Steps (16× faster).
7. Keyboard SE + Touch Strip
Matrix Src VeloAT: Velo / AT / Both | Kbd Src: Linear / S-Curve / Random / Voices | Bend Range: 1–12 st.
8. Seq
Smooth Mod 1–4: Step smoothing on/off | -1 / +1 Semitone: Transpose saved seq.
9. Scale Config Shift + Chord
Scale: Off/Global/User, Maj, Min, Dorian, Mixolydian, Blues, Pentatonic | Root: C–B.
10. Preset
View Snapshots: Restore time-stamped auto-saves | Details: Type, Designer & Rev #.
Utility Menu (Global) Shift + Sound Edit
1. Preset Operations
Preset Copy / Paste (Osc 1/2, FX 1–3, Seq+Mods, LFO Curve, Swap FX) | Preset Erase (Init, Reload, Matrix, Seq, Mods, Macro 1/2) | Panel Mode (Favorite vs. Knob Panel).
2. Controls (Feel & Response)
Knob Catch: Jump, Hook, Scale | Velo/AT Curve: Lin, Log, Expo | AT Sens: Low/Mid/High | Touch Sens: Low, Med, High | Sustain Polarity.
3. Audio & Calibration
Audio In Mode: Line vs. Mic (Dynamic) | Audio In Gain (-9 to +24 dB) | Master Tune (±50c) | Stereo to Mono | Calib Cutoff & Calib Analog.
4. Sync
Metronome (On/Off, Level, 1-Bar Count-In) | Clock Source (Auto/Int/USB/MIDI/In) | Clock/Transport Rx/Tx | PPQ | Global Tempo.
5. MIDI
In/Out Channels | MIDI From/To (USB/DIN/Both) | Local Control + MIDI Seq/Synth (4 routing modes) | Knob Send CC | Program Change.
6. Global Scale
Global Scale & Root: Default scale when preset Scale = Global.
7. Misc
LED Intensity | FW Version | Reset Settings (keeps presets).
8. Your Name
Set your designer name (tags your patches & adds to Filter list).
MiniFreak V Software Sync Rules
  • Standalone App: Hardware preset overwrites software on connect.
  • DAW Plugin: Plugin preset overwrites hardware on connect!
  • Backup Memory: Preset Browser → MiniFreak → Backup to Computer (right-click or Cmd/Ctrl+Shift drag to restore slots).
Custom Sample Transfer (v5.0) MiniFreak V
  • 1. Open Sample UI in V: Select a Wavetable/Sample-based engine in MiniFreak V, then click the sample name to bring up the UI.
  • 2. Import Audio: Click Import or drag & drop audio into V (target: 12-bit, 32 kHz, max 6s; user samples start with USR).
  • 3. Send to Hardware: Connect synth to reveal the Hardware Management section → click Send or drag & drop to transfer.
